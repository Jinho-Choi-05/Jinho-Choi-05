## 최진호 (Choi Jinho)

보안관제 엔지니어. 남겨진 흔적을 읽고 무슨 일이 있었는지 판단하는 일을 5년째 하고 있습니다.
반복되는 분석 절차를 자동화하는 도구를 만들고, 배운 것을 재현 가능한 형태로 기록합니다.

🔗 **[zino.kr](https://zino.kr)** — 기술 블로그 · 리서치 · 플레이그라운드 (자택 서버에 직접 구축·운영)

### Focus
- **디지털 포렌식** — 파일시스템 저장 구조 기반 아티팩트 식별·복원
- **분석 자동화** — 반복 분석 절차를 Python 도구로 만들어 배포
- **보안관제 · 침해대응** — SIEM 기반 이벤트 분석, 클라우드·온프레미스 관제
- **시스템 엔지니어링** — 도메인·인증서·리버스 프록시·WAF/IPS까지 전 구간 직접 운영
